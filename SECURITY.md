# Security Policy

## 🛡️ Supported Versions

We actively provide security patches and updates for the following versions of VERITAS:

| Version | Supported          |
| ------- | ------------------ |
| 4.1.x   | :white_check_mark: |
| 4.0.x   | :x:                |
| < 4.0   | :x:                |

---

## 📩 Reporting a Vulnerability or Security Issue

If you discover a security vulnerability, buffer overflow, memory safety issue, or unintentional privilege escalation bug in VERITAS, please do **NOT** open a public issue.

Instead, please report security issues privately:
- **Email**: `security@veritas-framework.org` (or contact repository owner directly via PGP/Email)
- **Response Time**: We aim to acknowledge receipt within 48 hours and provide a resolution or patch timeline within 7 days.

---

## 🚫 Safe Harbor & Scope

VERITAS is a security audit utility meant for authorized testing. We encourage responsible disclosure. Actions taken in good faith to test, discover, and disclose vulnerabilities within this project will be treated with full cooperation and appreciate your help keeping the project safe.
